# 资源释放与隐私配置修复记录

日期：2026-09-07。

本次针对代码审查中的资源泄漏、外部请求配置、文案准确性与自动验证缺口进行修复，保留此前的前端、PDF 和图片编码改进。

## 修复与复查

| 问题                                      | 处理结果                                                                                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 图片/视频临时 Object URL 未释放           | 媒体加载与绘制统一放入 `try/finally`，成功、加载失败、透明图片、Canvas 不可用、取消与超时均撤销 URL。监听器和计时器也会清理。                            |
| 移除文件/清空列表后音频封面泄漏           | 删除入口统一调用 `files.remove()` / `files.clear()`，撤销封面 URL，并使对应的缩略图任务失效。ZIP 展开和旧面板同步使用这些入口。                          |
| 删除时音频元数据仍在解析                  | 在解析返回后检查任务身份、取消状态和文件是否仍在队列中，避免创建迟到的孤立 URL。底层元数据解析本身不能同步中止，已开始的读取仍可能短暂继续。             |
| 音频封面读错字节范围                      | 从 `cover.data` 视图复制字节，不再复制整个底层 buffer。119 字节的测试封面此前会错误包含周围 ID3 数据，修复后可解码为 32 × 32 图片。                      |
| 极端长宽比缩略图消耗过大                  | 宽高均限制在 180 像素内，缩略图并发上限为 4，媒体加载超时为 15 秒。视频尝试使用首帧，避免额外 seek。                                                     |
| FFmpeg 绕过禁止外部请求开关               | 固定依赖 `@ffmpeg/core@0.12.10`，由 Vite 输出带指纹的本站 JS/WASM 资源；转换时才加载。音频和视频提取音频仍可使用。                                       |
| FFmpeg 异常时 Worker 残留、加载中不能取消 | 加载前登记实例，整个转换置于 `try/finally`；成功、加载失败和取消均终止 Worker 并移除实例引用。                                                           |
| Service Worker 仍允许缓存 CDN 引擎        | 缓存升级为 v4，只接受本站允许的引擎资源，删除旧版本缓存；仍排除带查询参数的开发模块、非 GET 与 Range 请求。                                              |
| 语言支持表述过度                          | README 明确为 15 个可选语言环境，新工作区/PDF/隐私/环保功能主要由英、西、简中、繁中覆盖，其他语言存在英语回退。本次没有宣称补齐全部翻译。                |
| 废弃支付依赖和政策文案                    | 删除两个 Stripe 依赖、15 个语言文件中的废弃捐赠/隐私摘要键，以及 Docker 和示例环境配置中的支付参数。同步修正文档中远程视频、分析统计与离线能力的旧描述。 |
| CI 未执行测试                             | 增加 `quality.yml`：PR、main 推送和手动触发均执行类型检查、单元测试、变更文件格式/ESLint 检查、生产构建与浏览器回归。安装使用冻结锁文件。                |

复查还修复了 SVG 转换的同类问题：在 Canvas 和图片对象准备成功后才创建 URL，给图片赋值失败时也执行清理。浏览器回归覆盖 Canvas 不可用时失败、恢复 Canvas 后成功重试，两个路径均无遗留 URL。

PDF 超时策略和编码器 Promise 不在本次修改范围：当前每次转换创建独立 Worker，并在结束或取消时终止；不能将后续复用 Worker 的假设当作现有的跨任务失败问题。

新增 CI 已完成本地对应检查，尚未推送，因此没有 GitHub Actions 远端运行结果；Docker 镜像也未在本次重建。

## 复现命令

建议使用 Node 22.22.2、Bun 1.4.0，与 CI 一致：

```sh
bun install --frozen-lockfile
bun run i18n:compile
bun run check
bun run test
bun run lint:changed
PUB_DISABLE_ALL_EXTERNAL_REQUESTS=true bun run build
bunx playwright install chromium
IIPE_EXPECT_NO_EXTERNAL=true bun run test:browser
```

浏览器测试会自行启动并清理 `127.0.0.1:5186` 的生产预览。`CHROMIUM_PATH` 可指定浏览器路径，`IIPE_TEST_BASE` 可指定已有服务。严格外部请求检查必须对应以该开关构建的产物；环境开关在构建时生效。

FFmpeg 本地资源约 31 MiB WASM 加 112 KiB JS，会增加部署文件体积，首次转换仍需从本站下载。固定版本及许可证信息保留在依赖包中；包声明为 GPL-2.0-or-later，来源为 [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm)。资源缓存不等于 PWA 已自动下载所有页面与引擎。
