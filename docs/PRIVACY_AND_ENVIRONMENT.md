# 本地隐私状态与环保反馈

更新于 2026-09-07。此改动延续现有 Pixel Desktop 界面，新增 `/environment/` 页面，并同步隐私页、首页状态、转换结果、导航和相关介绍文案。

## 隐私承诺的范围

- 当前注册的 ImageMagick、FFmpeg、Pandoc、MuPDF 均声明 `processingLocation: "local"`。没有启用远程视频转换器。PDF 引擎在首次转换时从本站按需加载，PDF 文件通过 Worker 消息传递并在浏览器内渲染。
- “文件上传量 0 B”表示这套本地转换路径没有文件上传，**不是整个浏览器的实时流量计**。说明入口就在指标旁。若注册表为空、包含远程转换器或未知处理位置，将不显示 0 B 承诺。
- 已移除 Google Analytics；本地模式不再探测视频服务器或通过 IP 服务选择服务器，设置页也隐藏未启用的远程转换配置。
- 四份友情链接徽章资源改为同源静态 SVG；保留原徽章外观和链接。SVG 未包含脚本或远程资源引用。
- 网页、字体和转换引擎仍有下载请求；FFmpeg 已随项目从本站按需加载。关于/致谢页在部署允许外部请求时按需获取 GitHub 的公开贡献者信息。隐私页明确说明资源提供商可能收到 IP 等连接信息，不承诺整个网站“没有网络请求”或主机“没有日志”。
- 文件内容、文件名和转换结果没有新增上传或遥测。队列统计仅从当前页面状态派生，未保存历史累计值。

实现入口：[转换器位置声明](../src/lib/converters/converter.svelte.ts)、[声明检查](../src/lib/util/conversion-privacy.ts)、[隐私状态组件](../src/lib/components/pixel/PrivacyStatus.svelte)、[隐私页](../src/routes/privacy/+page.svelte)。

## 存储影响模型 v1

模型定义在 [environmental-impact.ts](../src/lib/util/environmental-impact.ts)，用于展示**容量分摊的运行用电情景**，并非实测净减排、经核证的减排量或碳抵消。

| 输入           | 默认假设                                   | 来源                                                                                                        |
| -------------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| 每张图片节省量 | 原文件字节数减实际结果字节数               | 本地转换结果                                                                                                |
| 保留周期       | 365 天、一份持续通电的副本                 | 本页面情景假设                                                                                              |
| 单位容量功率   | HDD 0.65 W/TB；全球示例可切换 SSD 1.2 W/TB | [Cloud Carbon Footprint，2020 年模型估值](https://www.cloudcarbonfootprint.org/docs/methodology/)           |
| 电力排放强度   | 435 g CO₂/kWh，2025 年全球发电估计         | [IEA Electricity 2026](https://www.iea.org/reports/electricity-2026/emissions)                              |
| 全球示例人数   | 60 亿，2025 年估计                         | [ITU Facts and Figures 2025](https://www.itu.int/en/mediacentre/Pages/PR-2025-11-17-Facts-and-Figures.aspx) |

使用十进制单位，1 MB = 10⁶ 字节，1 TB = 10¹² 字节：

```text
用电量 kWh = 节省字节 / 10¹² × W/TB × 保留小时数 / 1000
CO₂ 克数 = kWh × 435
```

例如减少 1 MB，并按 HDD 情景保存一年，对应 0.000005694 kWh、约 2.48 mg CO₂ 的容量分摊值。数值很小时使用 mg 或“小于 0.01 mg”，不把毫克错误显示为克，也不增加树木、汽车里程等缺少依据的类比。

**全球每日示例使用逐日累计。** 每天开始时新增一份节省量，保留到第一年结束；365 份节省量分别保留 365、364……1 天。60 亿人每天各新增节省 1 MB，默认情景的计算结果为每天 6 PB、年末 2.19 EB，首年约 625 万 kWh、2,720 吨 CO₂。这是模型推算，不能把年末累计空间当成从年初就已经全部节省。

运行用电之外的制造影响仅用于科普，不计入每张图片换算；材料、制造和运输的生命周期说明参考 [Seagate](https://www.seagate.com/resources/working-toward-the-future-of-circularity/)。电子废弃物数据参考 [ITU / UNITAR 2024 报告](https://www.itu.int/en/ITU-D/Environment/Pages/Publications/The-Global-E-waste-Monitor-2024.aspx)，并注明报告覆盖全部电子废弃物。不当处理导致空气、土壤和水污染的说明参考 [WHO](https://www.who.int/news-room/fact-sheets/detail/electronic-waste-%28e-waste%29)。

模型不包括制冷、网络传输、制造和当前设备执行压缩的电耗，也不知道用户实际的硬盘、通电时间、备份和电力来源。删除文件不立即改变硬盘功耗。页面提示先确认画质并下载，再在合适时用压缩版替换原文件；程序不会自动删除原文件。

## 统计与交互规则

- 单张结果展示转换前后体积，以及正向体积差对应的一年 HDD 存储情景估算。
- 增大的结果显示增大体积；相同体积不计收益。队列净节省量包含正负体积差；净增加时不展示正向减排估算。
- 重复转换替换原结果；清空、删除、取消或切换目标格式会同步移除旧贡献。归档与未完成结果不计入。
- 环保页可调整每人每天新增节省的 MB 数和 HDD/SSD 情景。空值、非数值和越界值显示说明，结果显示 `—`。
- 新增文案完整覆盖简体中文、繁体中文、英语、西班牙语；其他语言通过 Paraglide 回退英语。切换语言同时更新 HTML `lang`。
- 手机版导航使用短标签，链接仍提供完整的无障碍名称。隐私页、环保页均支持亮色与深色主题。

## 验证与审查修正

自动测试在 [environmental-impact.test.mjs](../tests/environmental-impact.test.mjs)，覆盖十进制单位、mg 换算、逐日保留时长、两种存储系数、无效输入、体积增大抵扣、归档/取消排除、重复转换与本地声明边界。加上既有转换和 SW 测试共 33 项。

浏览器检查包括实际 PNG → WebP 下载字节差、重复转换、BMP 结果变大、清空队列、0 B 指标、计算器改值/清空/切换、移动端溢出、深色主题及五种语言（含法语回退）。未模拟拦截 Google Analytics；直接检查实际请求中无访问统计、定位探测和文件上传。

审查时修正了以下问题：

1. 将全站出站流量与文件上传量区分，避免用固定 0 B 冒充流量测量。
2. 移除旧版“视频除外”、服务器状态和“本地转换必然减碳”等冲突展示。
3. 使用 CO₂ 而非 CO₂e：所引用的 IEA 系数只覆盖发电二氧化碳。
4. 每日新增节省采用逐日保留时间，防止首年用电收益翻倍计算。
5. 汇总计算净体积差，防止只累计成功缩小的文件或重复转换刷累计值。
6. 不宣称点击转换已经释放磁盘空间，不将制造影响臆测为逐文件减排。
7. 修正 HTML 语言属性，并缩短手机上的环保导航标签。

最终构建、检查和浏览器记录保存在 [验证归档](privacy-environment/README.md)。
