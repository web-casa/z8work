# Phase 30 / R7：发行门禁 review 与交接准备

日期：2026-09-10。代码提交：`2f6190d`。**本轮完成 R7 可独立推进的预备开发与 review；R7 整体验收未完成，候选未冻结。** R5 的引擎/源码/许可缺项、R6 三端原生安装与剩余故障/性能验收仍然有效。七阶段没有新增 Phase 31，也不将最终准备工作误写成 V1 已完成。

## 本轮实际改动

复用 `desktop-candidate-check` 和 `desktop-store`，加强既有门禁，不再创建另一套发布流程。最终验收要求增加 `faults` 与 `performance`，其范围对应既有 R6 要求。验收摘要必须指明源码提交；每项具体报告必须匹配检查名称、产物、平台、架构、源码提交和确切包哈希。运行类检查要求声明原生执行；字节完整性、身份、许可和签名检查允许静态或人工审阅。所有通过报告都必须附有有界、实际存在且 SHA-256 匹配的原始证据引用。

独立候选检查与商店材料检查共用报告校验，防止从较弱入口绕过文件核对。哈希引用继续拒绝目录穿越、符号链接、缺失或变更文件。这里验证的是证据完整性与对应关系，**不能凭自述 `execution: native` 自动证明实机执行，更不能替代许可批准或签名身份验证**；结果仍需对原始日志、截图和运行环境进行人工 review。源码提交字段检查一致性，不自动证明该包由该提交构建；构建收据及源码差异仍按交接手册核对。

更新中英文商店草稿、隐私和支持页面：补充仅重试保存、暂存期限/预算、退出和重启后的处理，纠正临时文件只在输出目录的旧说明，并解释上传 0 B、潜在体积差额、环保估算及离线许可。保留桌面预览、商店尚不可下载的状态。生成四个本地静态页面，未部署到生产站。

文档浏览器验证器增加 `--pages-root` 和 `--output`，可使用独立输出保存新证据；同名目录存在时拒绝覆盖，并在创建服务器之前检查输出目录，避免错误路径留下监听服务。既有默认输入仍为 `build-pages`。本轮明确使用 `static` 下的生成文档，仅报告本地页面验证，不声称执行过完整网页生产构建。

## Review 发现与修复

| 发现                                                                      | 修复及证据                                                                   |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 相同包的一份转换报告可被引用为安装报告，门禁仍返回 ready-for-human-review | 先写负向测试复现，保留 `gate-before.log`；新增逐项身份校验，误用报告被阻断   |
| 未要求 R6 故障和性能材料，可在缺少两者时进入审阅就绪                      | 将两项纳入既有必需清单，逐项删除的回归测试通过                               |
| 单独候选 CLI 只核对摘要结构，没有读取具体报告                             | 复用商店检查的引用验证；真实 CLI 测试证明替换检查报告会失败                  |
| 同包报告未区分平台、源码或仿真执行                                        | 增加对应关系及原生执行声明约束；外平台、旧源码、仿真和静态运行类报告均被拒绝 |
| 只有汇总 JSON，原始证据可不存在或已改变                                   | 必须附原始文件引用，并读取核对 SHA-256；缺失和篡改测试通过                   |
| 支持文案遗漏 R2–R4 功能，临时文件位置说明过时                             | 对照 `retained.rs`、`workspaces.rs` 和实际发布路径更新双语内容               |
| 浏览器测试固定复用历史目录，可能覆盖旧截图                                | 新输出目录可配置，已存在目录实际执行返回 1，历史报告保留                     |
| 七阶段方案正文仍有“R6–R7 未开始”的陈旧状态                                | 同步总览、共用进度规则与 R7 预备状态，保留依赖未关闭                         |
