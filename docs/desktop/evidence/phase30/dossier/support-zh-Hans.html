桌面版使用与支持

桌面预览版说明。商店发行与跨平台安装验收仍未完成。

更新日期: 2026-09-10

当前可用状态

桌面版处于早期阶段，已有 Linux ARM64 本地验证。Windows x64 MSIX、Linux amd64 strict Snap、macOS ARM64 的原生安装验收仍待完成。本说明尚不提供商店下载链接。

支持的转换

图片可输出 PNG、JPEG、WebP 和 AVIF，PDF 可将页面导出为这些格式。音频可输出 WAV、MP3、FLAC、Opus 和 M4A，也可从支持的视频中提取音轨。Markdown 与 DOCX 可输出纯文本。本桌面版不支持 OCR、电子表格转换、保留排版的文档输出或视频输出。

仅重试保存已编码结果

任务显示“重试保存”时，可选择有足够空间的可写目录，将暂存结果保存下来，无需重读原文件或重新编码。取消目录选择会继续保留结果。暂存只限本次会话，空闲有效期 30 分钟，单文件最多 256 MiB，总计最多 1 GiB。退出前请先保存结果。暂存过期、损坏或不可用时需重新转换；重启后需重新选择原文件和输出目录。PDF 页面恢复使用独立的重试流程。

隐私、体积估算与许可

“文件上传 0 B”说明转换在本机执行，不是应用或整台设备全部网络流量的实时计量。打开外链会使用系统浏览器。图片体积差额比较已保存结果与仍保留在磁盘上的原图，环保估算不代表实测碳减排。应用内可离线阅读隐私说明和开源许可。

转换中断或输出变大

重启后请先重新选择输入文件与保存目录，再重试。PDF 部分完成时，使用相同文件、保存目录和参数重试未完成页，可保留已校验的结果。图片压缩无法保证一定变小，请比较结果体积，并按需要降低质量档位。

反馈问题

请说明操作系统与架构、应用版本及安装包来源、输入和输出格式、质量与 PDF 分辨率设置，以及完整错误文本。应用中可查看原生引擎版本。请隐去个人路径，优先使用人工生成的样本。公开 issue 对他人可见；需要私下沟通时可使用邮箱。
