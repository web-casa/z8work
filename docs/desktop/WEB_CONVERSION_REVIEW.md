# 网页引擎桌面迁移：review 与验证

日期：2026-09-20。范围为 `feat/desktop-web-conversion` 相对原生快照 `00389e9` 的改动。

## Review 结论

已完成本轮自审，并修复以下问题。在已验证的 Linux ARM64 开发预览范围内，未发现未处理的阻断问题。
这不是 Windows/macOS、商店发行、正式签名或全格式支持认证。

| 检查项                         | 处理结果                                                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 转换实现重复                   | 直接打包现有网页工作区和转换器，桌面不再编译或调用 `z8-native`；旧原生引擎工作流退出活动目录。                               |
| WebView 不能依赖浏览器下载行为 | 单文件和 ZIP 导出统一等待原生保存完成，错误回到已有 UI 提示，结果 Blob 保留供重试。                                          |
| 一次性 IPC 传输大文件          | 保存按 1 MiB 分块发送二进制，Rust 再验证块大小与总长度；不使用 Base64 或 JSON 数字数组。                                     |
| 未完成保存破坏已有文件         | 同目录临时文件、完整长度校验、同步及原子发布；取消、超长或不完整写入不会截断目标。                                           |
| 路径与权限                     | 前端只提供文件名建议和字节，目标路径由系统对话框产生；后续操作只接受随机 token。没有任意路径读写、shell 或原生转换命令权限。 |
| 重复保存与退出                 | 保存互斥，取消/失败后解除；有任务或保存进行中时关闭窗口需要确认。                                                            |
| 外链替换工作区                 | 原生导航仅放行应用 origin（开发时为固定本地端口）；外链走系统浏览器，不创建新的应用 WebView。                                |
| 打包后离线可用                 | 6 个 WASM 资源随包嵌入，构建核验 WASM 文件头；桌面停用 Service Worker，避免旧缓存替换随包资源。                              |
| 内存竞争                       | 桌面批量转换顺序执行；共享网页行为和格式规则保持不变。用户单独发起的并行操作仍受可用内存限制。                               |
| 旧行为说明失真                 | 新增迁移说明，更新双语桌面隐私/支持页；旧商店、签名和原生格式材料明确保留为历史参考。                                        |

## 剩余验收边界

1. Windows/macOS 及 Linux x64 的真实 WebView、文件选择、拖放、保存、退出和安装验收。新六平台 CI 已配置，但本轮没有远程执行记录。
2. 正式发行所需的签名、公证、MSIX/Snap 商店材料、更新与升级兼容性。旧原生版证据不可复用。
3. 大文件、长时间批量、低内存、磁盘满、断电及全格式矩阵。现有单元故障测试不能替代所有平台真实故障测试。
4. 旧队列与偏好不迁移，任务结果仅在会话中保留；不提供旧原生版的重启恢复、原生诊断及 PDF 部分页重试。
5. 新 WASM 与外壳依赖的正式许可/源码发行包需要按确切 release 构建重新核对，不沿用原生引擎许可包。

## 接口依据

二进制 IPC 使用 [Tauri 官方 Rust 调用文档](https://v2.tauri.app/develop/calling-rust/) 中的 ArrayBuffer 请求接口；
离线前端采用 [Tauri 静态前端要求](https://v2.tauri.app/start/frontend/)。
系统保存、导航和弹窗接口同时核对了本地锁定版本的 Rust 依赖源码。
