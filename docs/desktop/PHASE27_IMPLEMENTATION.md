# Phase 27 / R4：产品体验、隐私与格式质量

日期：2026-09-09。本阶段交付桌面双语文案、隐私和环保说明、键盘/缩放修复，以及 [84 条格式路线的真实样本矩阵](PHASE27_FORMAT_MATRIX.md)。保留首版格式和语言边界；性能测量的适用范围见 [性能预算表](PHASE27_PERFORMANCE.md)，原生安装与公开发行仍待 R5/R6/R7 验收。

## 用户可见的变化

- 右上角继续提供语言切换；结果说明、偏好/缓存/历史失败提示和诊断操作建议均使用受控双语文案，不直接展示原始引擎/系统错误。文件名、路径、引擎版本、文献名称与明确供复制的诊断 JSON 保留原样。
- 原生文件选择、输出目录和诊断保存窗口按已保存的语言偏好显示标题；跟随系统时使用双语标题，避免窗口尚未加载时依赖 WebView 判断。系统文件对话框的按钮语言由操作系统提供。
- 隐私区显示“在此设备处理 · 文件上传 0 B”。只有后端返回 `device-v1` 能力标记且队列中全部路线属于冻结的本地路线时显示 0 B；初始化、未知能力或未知路线不作该声明。这不是流量监控或整机防火墙，也不包含云同步目录、其他应用、系统/商店更新。
- 环保说明随程序打包，离线可读。只比较当前队列中完整保存的图片，增长抵扣减少；重试及重复事件不累计，失败/部分完成/待保存不计入，清空即重置。恢复的保存历史按保存时记录比较，不扫描磁盘或保证输出仍存在。
- 明确原文件仍保留：显示的是结果相对原图的潜在存储减少，不是已释放空间、测得的节电或碳抵消凭证。
- 最小窗口与 200% 布局缩放下，顶栏、语言选择和操作区允许换行；保留像素图标。提供跳到工作区的键盘入口，清空后焦点回到“选择文件”，输入框/诊断文本框有可见焦点。

## 实现与权限

[impact.ts](../../desktop/src/platform/impact.ts)直接使用原生任务快照，复用网页环保模块的纯函数，不加载网页 store、浏览器 `File`、WASM 转换器或网络服务。统计为当前快照派生值，不新增持久化计数器或修改历史 schema；重复任务取最后状态，正在重试的旧成功结果不会继续计数。

[Impact.svelte](../../desktop/src/Impact.svelte)包含离线说明和来源入口。[Rust 来源映射](../../src-tauri/src/impact.rs)仅接受五个固定来源 ID，再调用已有 opener 库交给系统浏览器。新增 IPC 不接受 URL、文件路径、浏览器命令或任意参数；原有文件授权与 CSP 边界保留。来源需要用户点击才打开；这会连接外部网站并暴露浏览器 IP，界面已说明。有效链接由系统浏览器打开的目标平台实测仍在 R6；本轮验证固定映射及拒绝任意 URL，没有为测试访问真实外站。

[dialogs.rs](../../src-tauri/src/dialogs.rs)集中提供原生对话框标题。结果说明仅翻译应用已知模板；未知内容使用通用提示。诊断 JSON 的原始字节不改变，过期的报告 token 仍被后端拒绝，并提示重新预览后保存。

## Review 与修正

按 code-reviewer 的安全、正确性与维护性顺序复查，实际修正如下：

1. 消除界面中残留的英文底层错误；保留过期诊断报告“重新预览”的具体恢复建议，未破坏精确字节确认机制。
2. 修复 200% 缩放时语言框越界、窄窗口品牌图标被通用 `span` 规则隐藏，以及清空后的焦点丢失。没有用隐藏横向溢出来掩盖布局问题。
3. 环保统计按已保存状态和任务 ID 去重；增加增长、清空、重复事件、重试、未保存、PDF/媒体排除与未知执行路线的测试；存储介质校验改为自有属性匹配。
4. 原有静音音频只能证明解码成功，无法证明声音保留。换用双声道不同频率信号，检查时长、声道及真实振幅。图片补齐 JPEG/HEIF 别名、ICC、方向和透明度；PDF 补基础/嵌入字体像素验证。
5. 质量验证器既能接开发引擎，也提供 `bundle-check ENGINE_DIRECTORY --quality` 给后续候选复测；未知选项继续拒绝，不增加桌面 IPC。
6. GUI 测量工具默认复制开发程序再启动，防止重新编译替换正在运行进程的可执行文件而影响 watchdog。显式传入 `Z8_GUI_BINARY` 时保留原布局，适用于调用者提供的资源目录。启动测量保留失败的原始阶段与状态，修复清理路径重复创建活动会话而覆盖首个错误的问题；允许人为阻塞的探测达到既定超时后变为失败，仍要求首屏可交互时处于准备中、其他引擎独立就绪。

冻结样本均通过，未改写质量预设或悄悄换输出格式。照片体积表展示同一预设名称下的实际结果，不能当作相同视觉质量的编码器排名。

本机 MuPDF 在独立字体渲染复核时提示 ICC 支持不可用（见 [原始提示](evidence/phase27/pdf-render-note.txt)）。因此图片 ICC 字节保留的通过结论不能扩展到 PDF 色彩管理。R5 必须确认候选引擎的 ICC 构建选项，R6 补含 ICC 的 PDF 样本；此项未关闭。
