2026-09-15 的格式扩展不是对现有预览包的追补说明，而是新的源码和最终包验收周期。已完成的逐项决策、修复、本地门禁和失败原始记录见[格式扩展开发记录](FORMAT_EXPANSION_DEVELOPMENT_LOG.md)；其 Linux ARM64 完整矩阵仍在进行中，retry-5 最后可见为 WMA→Opus 解码读回，随后在未归因的有界步骤 timeout；同引擎的九条 WMA 输出缩小复现通过，仍尚未产出完整 JSON。因此本轮不能更新公开格式承诺、替换现有候选，或将结果外推到其他平台。

## 范围与外部条件

- 当前版本无自动更新器。是否引入自动更新需明确渠道策略；它不应隐含为“已有更新能力”，也不必作为所有手动分发渠道的强制前置。
- Windows ARM64 的部分引擎仍经 x64 模拟运行，保持已披露的客观兼容边界。
- 当前不新增 ARM64 Snap、AppImage、MAS、OCR、Excel、完整视频转码或更多语言；这些不混入必需剩余数量。
- GitHub 原生 runner 可以验证对应系统，但不自动代表用户的干净账户、最低系统版本和真实权限提示均已覆盖。逐项写明环境与限制。
- 签名凭据沿用已配置 Secrets。本次复用已签名包，无需再次签名或公证。
