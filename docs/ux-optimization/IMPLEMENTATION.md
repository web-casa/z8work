# 工作区优化实施与代码审查

日期：2026-09-07。对应 [PLAN.md](PLAN.md) 的第 1、2 批，以及第 3 批中格式菜单关闭、焦点和错误展示的基础修正。保留已有 Pixel 视觉、隐私与环保功能、图像转换引擎和质量策略。

## 本次实现

- 桌面使用紧凑文件行和 330px 输出栏；主按钮放在输出栏上方，高度足够时随滚动保持可见。手机不大于 800px 时，同一套格式和主操作控件移至底部；通过 ResizeObserver 实测高度，为页脚和滚动留出空间，离开工作区时清理。
- 上传入口在组件挂载后才启用，避免页面重载时在事件尚未绑定前选择文件而丢失操作。
- 文件名改用正文字体、两行显示和行内展开，扩展名单独展示。名称作为纯文本按文件 ID 绑定；展开后焦点留在名称按钮。
- 卡片、批量操作、页脚共用 `queue-state.ts` 的互斥状态与汇总。待处理、失败、取消分别选择执行对象；一个不支持的输入不再阻止其他文件转换。成功结果保留，重新转换全部需要展开说明后单独执行。
- 相同目标格式为无操作；真正改变目标才清除该文件的旧结果和错误。质量和元数据设置不清除结果。
- 单个完成结果直接下载实际格式；多个完成结果才打包 ZIP。ICO 等实际返回 ZIP 的单个结果不再外包一层。点击下载时固定结果文件引用、名称和扩展名；使用原 File/Blob，无须为打包额外读取完整 ArrayBuffer。
- 下载名称冲突时加序号，避免不同源格式转为同名输出后在解压时覆盖。保留 ii.Pe 命名模板及其中的字面 `$` 字符。
- 格式候选检查输入/输出方向、native 路径、文件大小；批量菜单保留相同转换器集合的条件，再取合法交集。没有共同候选时分别选择。设置页的菜单也过滤只读格式。
- 继续使用现有 FormatDropdown，改用原生 dialog 承载菜单：手机先聚焦关闭按钮、桌面聚焦搜索；Esc、关闭和选中后恢复焦点；宽度变化安全关闭，搜索面板使用 visualViewport 可用高度。菜单关闭时不渲染格式按钮，控件 ID 使用 Svelte 的组件实例 ID。
- 引擎详细错误留在对应文件的展开区域，通知缩短为失败和恢复指引。通知可通过有名称的 44px 按钮关闭，列表高度受限，并避开手机固定栏。下载失败保留转换结果并释放下载锁。
- 新文案覆盖英文、西班牙语、简体和繁体中文；其他语言沿用项目的英文回退。

主要代码：[工作区](../../src/lib/components/pixel/ConversionWorkspace.svelte)、[文件行](../../src/lib/components/pixel/PixelFile.svelte)、[状态](../../src/lib/util/queue-state.ts)、[输出候选](../../src/lib/util/output-formats.ts)、[下载](../../src/lib/util/download.ts)、[格式菜单](../../src/lib/components/functional/FormatDropdown.svelte)、[布局](../../src/lib/css/workspace.scss)。

### 复现

使用 Node 22。在仓库运行开发服务器，或构建后启动生产预览：

```bash
npm run dev -- --host 0.0.0.0 --port 5174
npm run build
npm run preview -- --host 0.0.0.0 --port 5184
```

脚本使用已安装的 Playwright 和本地 Chromium；不将它们加入应用依赖。按本机安装位置指定路径：

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
CHROMIUM_PATH=/usr/bin/chromium \
IIPE_TEST_BASE=http://localhost:5184 \
IIPE_TEST_OUTPUT=/tmp/iipe-workspace-validation \
node tests/browser/workspace.mjs
```

`PLAYWRIGHT_MODULE` 可省略，此时按常规 Node 模块路径加载 `playwright`。脚本使用仓库素材，不需要用户的原始图片。
