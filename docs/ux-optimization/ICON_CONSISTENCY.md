# 全站像素图标走查

日期：2026-09-07。

## 来源

界面功能图标来自仓库已安装的 **Pixelarticons 2.4.1**，采用 MIT 许可，通过 [PixelIcon.svelte](../../src/lib/components/pixel/PixelIcon.svelte) 显式导入包内 SVG，并用 CSS mask 继承文字颜色。它们是图标库素材，并非本项目逐个手绘，也不是把普通图标栅格化后加马赛克滤镜。图标随应用打包，无需外部图标 CDN。

Z8 的 favicon、PWA 安装图标等品牌素材是项目自定义的像素 SVG；[生成脚本](../../scripts/generate-brand-assets.mjs)用像素字形矩阵绘制 Z8，再导出 PNG。页头字标采用 Pixelify Sans 字体。它们与功能图标库是不同来源。

## 发现及修复

实测修改前，关于页渲染了 11 个 Lucide 图标，设置页默认状态 21 个，致谢页 6 个；首页、转换工作区、隐私和环保页面已使用像素图标。

共迁移 18 个组件/页面文件，统一复用 `PixelIcon`，覆盖：

- 关于页标题、为什么选择、九项功能介绍、致谢标题、贡献者与资源链接。
- 设置页标题、转换、外观、隐私、播放/暂停、主题切换、刷新、删除及下拉箭头。
- 通知的成功、失败、信息、警告状态和关闭按钮，以及确认对话框。
- 未在当前页面启用的旧导航、上传、转换面板、赞助区及远程设置组件，避免以后启用时重新混入旧图标。

方形图标底托集中在 [pixel.scss](../../src/lib/css/pixel.scss)，由外层容器绘制背景和边框，内部只显示图标遮罩，避免背景或内边距影响 SVG 图形。离线能力使用设备图标，隐私设置使用锁图标。通知与对话框按类型映射到像素图标名；名称受 TypeScript 联合类型约束。

源码中不再引用 `lucide-svelte`，已移除其依赖及对应锁文件条目；没有升级其他依赖。友情链接品牌标识、贡献者头像、用户文件预览和历史设计稿仍属于原始图片素材，未作为界面功能图标替换。

## 自审与验证

- 检查所有图标导入及动态图标映射；保留装饰图标的 `aria-hidden="true"`，按钮的可访问名称继续来自文本或原有标签。
- 避免直接把原 SVG 的背景/内边距样式套到遮罩上；将其移到方形底托。下拉箭头旋转保留在外层容器，图标本体由 `PixelIcon` 渲染。
- 同步清理触及文件中的未使用导入/变量；现有翻译 HTML 仍经过共享白名单清洗，逐处注释说明 ESLint 例外的边界。
- 类型检查：0 错误、0 警告；变更文件的 Prettier 与 ESLint 通过。
- 开发预览检查了首页、转换、关于、设置、致谢、隐私、环保七个路由，覆盖明暗主题及 320/390/1366px 三个宽度，共 42 组：无 Lucide 节点、无横向溢出，图标遮罩及尺寸有效，底托保持方形，图标资源无加载失败。
- 实际触发并取消网站数据确认框，触发损坏图片的转换错误并关闭通知，验证动态状态图标及操作仍然有效。

生产构建成功；同样的 42 组图标检查在生产预览复验通过，页面脚本与图标资源错误均为 0；已有 `tests/browser/workspace.mjs` 回归通过，覆盖真实转换、重试、取消、下载、语言切换、移动端操作和格式选择。文档链接及 Git 空白检查通过。本轮为实现者自审与 Chromium 浏览器验证，不代表真实设备或完整读屏器验收。
