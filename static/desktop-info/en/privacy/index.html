Desktop privacy

Desktop preview documentation. Store releases and cross-platform installation acceptance are still pending.

Updated: 2026-09-08

Files stay on your device

The desktop converter reads the files you select, runs native conversion engines locally, and writes results to your chosen folder. It does not upload file contents. The desktop application has no account, advertising or analytics service.

Local history and temporary files

Task history stores file names, sizes, conversion settings, status, and output paths and hashes in the application's local data directory. File paths and names may contain personal information. Temporary working files are normally removed when a task ends; an abnormal process or system crash can leave temporary data in the selected output folder.

Clearing data

Clear file list removes current task history after active work stops. It does not delete your source files, saved outputs, or history backups retained during a schema upgrade. Remove those files yourself if you no longer need them. Removing an application copy may leave its local data; package managers can also retain backups or snapshots.

File access

You select source files and a destination through system dialogs. Restored history does not restore file access: reselect files and the output folder before retrying. Operating-system sandbox and portal access depend on the actual installed package and must be tested per platform.

Connections outside conversion

Bundled-engine conversion does not require a conversion server. Installing or updating the app, operating-system components or a store client may use the network. Opening this website, source code or support email uses your browser or mail provider under their own policies. This documentation is distinct from the web converter's privacy policy.

Contact and voluntary reports

If you email support or open a public issue, the information you choose to send is received by the mail or issue-hosting service and the project maintainers. Remove private paths, personal metadata and sensitive file contents. A minimal synthetic sample is usually sufficient; there is no automatic diagnostic upload.
