Desktop privacy

Desktop preview documentation. Store releases and cross-platform installation acceptance are still pending.

Updated: 2026-09-20

Local web engines

The desktop app bundles its interface and WebAssembly conversion engines. Files are processed on your device, without a conversion server or file uploads. It does not install or launch native FFmpeg, ImageMagick, Pandoc or MuPDF programs. There is no account or analytics service.

Session data and preferences

Selected files and converted results are held in the current session. Closing the app loses the queue and unsaved results. Language, theme and conversion preferences may persist in local WebView storage. The app does not import or delete history from the previous native-engine version.

Saving and temporary files

You select a destination file through a system save dialog. Output is written to a temporary file beside the selected destination and published only when complete. Cancelled and failed saves normally remove the temporary file; a process crash can leave one behind. Clearing the file list does not delete source files or saved outputs.

External links and support

Opening a website or support email uses your system browser or mail application. Installing and updating software can use the network. Information you voluntarily send to support is handled by the recipient and its provider; no diagnostic report is automatically uploaded.
