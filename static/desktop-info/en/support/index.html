Desktop support

Desktop preview documentation. Store releases and cross-platform installation acceptance are still pending.

Updated: 2026-09-08

Current availability

This is an early desktop version. Linux ARM64 local validation exists. Windows x64 MSIX, Linux amd64 strict Snap and macOS ARM64 native installation acceptance remain pending. There are no Store download links in this documentation.

Supported conversions

Image output: PNG, JPEG, WebP and AVIF. PDF exports pages to those image formats. Audio output: WAV, MP3, FLAC, Opus and M4A; supported videos can supply an audio track. Markdown and DOCX can export plain text. This desktop version does not support OCR, spreadsheet conversion, formatted document output or video output.

When conversion stops or output grows

After restarting, reselect the input and save folder before retrying. For a partially completed PDF, retry unfinished pages with the same file, output folder and settings to preserve verified results. Image compression cannot guarantee a smaller file; compare output sizes and choose a lower quality preset where appropriate.

Reporting a problem

Include your operating system and architecture, app version and package source, input/output formats, selected quality and PDF resolution, and the exact error text. Native engine versions are shown in the app. Redact personal paths and use a generated sample where possible. Public issues are visible to others; email is available for private correspondence.
