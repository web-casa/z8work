Desktop support

Desktop preview documentation. Store releases and cross-platform installation acceptance are still pending.

Updated: 2026-09-20

Preview version

This branch uses the same conversion code and workspace as the web app. Linux ARM64 WebView conversion and system saving have been tested. A previous macOS ARM64 preview passed signed installation tests; final packages containing the latest changes and store releases are still pending.

Conversion capabilities

Image, audio, document and PDF conversion use bundled WASM engines. Supported formats and settings are shown in the app. Native-only format extensions from older desktop versions are not promised. Remote video conversion is not enabled.

Save or retry

Use the download action to choose a destination. Cancelling the dialog keeps the converted result. After a write failure, use the action again to choose another writable location without converting again. Save results before closing the app.

Resource limits

WASM conversion is limited by WebView capabilities and available memory. Desktop batch jobs run sequentially; large inputs or ZIP outputs may still exceed available memory. Save operations accept at most 2 GiB. Restart recovery and partial PDF-page retry from the old native version are not available.

Updates

Store builds receive updates through their store. Direct-download builds link to the project's release page. The app does not download or install updates by itself.

Reporting issues

Include the operating system, architecture, app version, input and output formats, settings and error message. Prefer a small synthetic sample; remove personal paths and confidential contents before sharing.
